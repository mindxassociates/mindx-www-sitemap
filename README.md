# mindx-www-sitemap

Manually maintained XML sitemap for https://www.mindx.us/ (a Google Sites site, which
publishes no sitemap of its own). Hosted on GitHub Pages under the practice's own
domain at https://projects.mindx.us/mindx-www-sitemap/sitemap.xml and submitted to
Google Search Console (Domain property sc-domain:mindx.us) — Google allows a sitemap
hosted on one verified host to list URLs of another verified host.

Regenerate: crawl www.mindx.us internal links, keep only live (HTTP 200, non-redirect)
canonical www URLs, rebuild sitemap.xml, commit, and confirm the GSC status stays
"Success". URL list snapshot: urls_clean.json (117 URLs, verified 2026-11-10).
